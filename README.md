# مدار

منصة شخصية لتنظيم وقت الدراسة: جدول المواد حسب الأسابيع والشهور، مهام يومية وأسبوعية وشهرية، مؤقت بومودورو، ملاحظات، آية وحديث وحكمة تتغير كل يوم، وأنشطة قصيرة للاستراحة.

## الملفات

- `index.html` هيكل الصفحة والتنقل
- `css/app.css` التصميم
- `js/app.js` منطق الصفحات والحفظ
- `js/content.js` الآيات والأحاديث والحكم والأنشطة والقصص
- `js/outlines.js` مواعيد المواد المستخرجة من ملفات الأوتلاين
